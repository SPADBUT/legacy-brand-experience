# App Evelyn — Clínica Estética

O aplicativo clínico da Evelyn (V1) está em:

**[`evelyn-clinic/`](./evelyn-clinic/)**

```bash
cd evelyn-clinic
npm install
npm run dev
```

Módulos da V1: prontuários, agenda, fotos antes/depois, termos de consentimento, contratos e orçamentos.

Roadmap completo (V1 → V2 CRM → V3 financeiro): [`evelyn-clinic/ROADMAP.md`](./evelyn-clinic/ROADMAP.md)

O site institucional da Legacy Brand Experience permanece na raiz deste repositório.
